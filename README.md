# StaffSync - MERN Human Resource Management System

Roles: HR, Manager, Employee. Features: JWT auth, role-based access, employee CRUD, attendance,
leave workflow, announcements, training programs, responsive dashboards.

## Run it
1. Start MongoDB (local service or MongoDB Compass connection on mongodb://127.0.0.1:27017).
2. Backend:   cd server && npm install && npm run seed && npm run dev      (http://localhost:8000)
3. Frontend:  cd client && npm install && npm run dev                      (http://localhost:5173)

Demo logins after seeding (password Password@123):
HR hr@staffsync.com | Manager manager@staffsync.com | Employee employee@staffsync.com
